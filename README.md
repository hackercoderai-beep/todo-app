# todo-app

A small command-line to-do app written in JavaScript. When you run it, it prints a `Tasks` heading followed by the list of tasks defined in `todo.js`.

## Requirements

- [Node.js](https://nodejs.org/) installed (check with `node --version`)

## How to run

1. Open a terminal in the repository folder.
2. Run the app with Node:

   ```sh
   node todo.js
   ```

The tasks are printed straight to the terminal. To change them, edit the `tasks` array at the top of `todo.js`.
